# Powai Window Fix

BUILD A HIGH-CONVERTING LOCAL LEAD GENERATION WEBSITE

FOR A WINDOW / ALUMINIUM REPAIR BUSINESS IN POWAI, MUMBAI.



IMPORTANT:

This is NOT a normal corporate website.

This is NOT a brochure website.

This is NOT primarily designed to explain the company.



The primary purpose of this website is:



GOOGLE SEARCH / LOCAL TRAFFIC

        ↓

CUSTOMER HAS A WINDOW PROBLEM

        ↓

CUSTOMER FEELS UNCERTAIN

        ↓

WE REMOVE THE UNCERTAINTY

        ↓

CUSTOMER SENDS PHOTO ON WHATSAPP

        ↓

BUSINESS RESPONDS

        ↓

SERVICE / VISIT

        ↓

REPAIR

        ↓

REVIEW



Use a direct-response marketing philosophy inspired by Sabri Suby's

lead-generation approach:



AUDIENCE → PROBLEM → PROMISE → AGITATION → SOLUTION → PROOF → OFFER → CTA



Do NOT copy Sabri Suby's copyrighted material or exact wording.

Use the underlying direct-response principles only.

1. BUSINESS POSITIONING

==================================================



Business category:



Window Repair / Sliding Window Repair / Aluminium Window Repair



Primary location:



Powai, Mumbai



Target areas:



Powai

Hiranandani Gardens

Chandivali

IIT Powai

Saki Vihar

nearby Powai areas



Primary customer:



A homeowner / tenant / office owner who currently has a window,

sliding door, aluminium frame, glass, roller, lock, handle or track

problem.



The customer usually does NOT know the technical name of the problem.



Therefore the website should communicate:



"You don't need to know what's wrong.

Just show us the problem."



This is the central marketing idea.

19. WHATSAPP FUNCTIONALITY

==================================================



Create a configurable WhatsApp number in one central configuration

file.



Example:



WHATSAPP_NUMBER = "91XXXXXXXXXX"



Do NOT hardcode the number throughout the application.



Every WhatsApp CTA should use the same configuration.



Use a pre-filled message.



Example:



"Hi, I have a window problem in Powai.

I am sending a photo/video of the problem.

Please help me understand what may be wrong."



Important:



A normal website cannot automatically attach a customer's local

photo to WhatsApp through a basic wa.me link.



Therefore:



CLICK BUTTON

→ OPEN WHATSAPP

→ PREFILLED MESSAGE

→ CUSTOMER ATTACHES PHOTO



Do not falsely advertise:



"Upload photo and automatically send it"



unless a proper backend / WhatsApp API implementation exists.
